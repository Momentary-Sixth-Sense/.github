한 번 만들어 두고 계속 써먹을 도구로 바꿉니다.

귀찮음을 발견하면 저장소가 하나 늘어납니다.

## 꿀 빠는 법

- 복붙이 길어지면 스크립트를 만듭니다. 손목은 오래 써야 하니까요.
- 매일 확인할 일은 알림으로 받습니다. 새로고침에도 인건비가 듭니다.
- 처음 쓰는 사람도 쉽게 시작하게 만듭니다. 설치하다 퇴근 시간이 지나면 곤란합니다.
- 다시 쓸 코드와 사용법을 남깁니다. 다음에 헤맬 사람은 대개 미래의 우리입니다.

이제 이거 손으로 안 해도 됨
